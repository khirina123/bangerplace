# Сайт шоу-плейса «БЭНГЕР»

## Что внутри

- `index.html` — главная страница;
- `bibirevo.html` — страница для Бибирево;
- `altufevo.html` — страница для Алтуфьево;
- `vr.html` — страница VR-праздника;
- `prices.html` — пакеты и цены;
- `blog.html` — раздел с SEO-статьями;
- `blog-*.html` — отдельные полезные статьи для родителей;
- `styles.css` и `script.js` — локальные стили и сценарии;
- `sitemap.xml` и `robots.txt` — файлы для поисковых систем;
- `assets/` — оптимизированные изображения и видео.

Файл `bribirevo.html` оставлен только как переход с ошибочного написания на правильный адрес `bibirevo.html` и закрыт от индексации.

## Публикация на GitHub Pages

1. Создайте репозиторий GitHub и загрузите в его корень содержимое папки `dist`.
2. В репозитории откройте **Settings → Pages**.
3. Выберите **Deploy from a branch → main → /root**.
4. Проверьте временный адрес `ваш-логин.github.io/имя-репозитория`.
5. В поле **Custom domain** укажите `bangerplace.ru`.
6. После проверки измените DNS-записи домена по подсказке GitHub и включите **Enforce HTTPS**.
7. Добавьте сайт в Яндекс Вебмастер и отправьте `https://bangerplace.ru/sitemap.xml`.

## Перед переносом домена

- заменить три карточки-заглушки на настоящие отзывы со ссылкой на источник;
- проверить окончательные цены и ограничения по числу гостей;
- перенести оферту, политику и согласие на новый сайт или сохранить действующие ссылки;
- подключить Яндекс Метрику и цели для Telegram, MAX и звонка;
- настроить 301-переадресацию со старых адресов, если они меняются.
